# Will You Be Mine? 💖

A playful proposal page made with HTML, CSS, and JavaScript. The "No" button runs away, the "Yes" button keeps growing, and a love letter types itself out when you say yes.

Live demo: https://tanmanpo.github.io/will-you-be-mine/

## Features
- Personalized with a name (type it in, or use `?to=Name` in the link)
- A "No" button that dodges the cursor and finger
- Falling hearts and a typed love letter on "Yes"
- Works on phones

## Built with
HTML, CSS, JavaScript

## What I learned
- How to move elements with JavaScript and `Math.random()`
- How to use CSS animations
- How to host a site with GitHub Pages
